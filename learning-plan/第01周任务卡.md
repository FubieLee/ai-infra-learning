# 第 01 周任务卡（Phase 0 · Week 1）
> 主题：Linux/Shell + Git + 开发环境搭建
> 覆盖知识图谱节点：D2-4（Linux 与 Shell）、D3-4（工程工具链 部分）
> 预计每日投入：工作日 2–3h，周末 4–6h

---

## Day 1（周一）：Linux 基础与 Shell 基本功
- **学习**：文件系统、权限、进程管理、管道与重定向（MIT Missing Semester 第 1–2 讲）
- **练习**：写 5 个一条命令完成的任务（例：统计目录下 .cpp 文件总行数；找出占用最高的 5 个进程）
- **验收**：把 5 条命令 + 输出贴给我，并解释每段含义

## Day 2（周二）：Shell 脚本与文本处理
- **学习**：grep/sed/awk 三剑客、shell 脚本基础
- **练习**：写一个脚本 `logstat.sh`，解析任意 nginx/训练日志，输出错误类型 Top5 及占比
- **验收**：脚本 + 对样例日志的运行结果

## Day 3（周三）：Git 核心机制
- **学习**：工作区/暂存区/对象模型、分支与合并、rebase vs merge、冲突解决
- **练习**：在练习仓库中故意制造冲突并解决；用 `git log --graph` 画出分支历史
- **验收**：回答 3 个问题（HEAD 是什么？rebase 改写了什么？fast-forward 条件？）+ 分支图截图

## Day 4（周四）：开发环境搭建（关键日）
- **任务**：搭好训练环境——本地双系统/WSL2 或云 GPU 服务器（AutoDL/趋动云均可）
- **检查清单**：NVIDIA 驱动 ✓ CUDA Toolkit ✓ cuDNN ✓ conda/uv ✓ PyTorch GPU 版验证 `torch.cuda.is_available()` ✓ VSCode Remote-SSH ✓
- **验收**：截图 `nvidia-smi` + PyTorch CUDA 验证结果

## Day 5（周五）：编辑器与调试工具链
- **学习**：VSCode 配置（C++/Python）、gdb/pdb 基础调试、tmux 会话管理
- **练习**：用 tmux + gdb 调试一个故意写崩的 C++ 程序（段错误），定位到出错行
- **验收**：描述段错误原因 + gdb 调试过程

## Day 6–7（周末）：周综合小项目 + 复盘
- **项目**：写一个"GPU 资源监控脚本" `gpuwatch.sh`：定时采样 nvidia-smi，记录显存/利用率到 CSV，超出阈值报警
- **复盘**：填写本周学习进度记录（见 `progress/学习进度记录.md`），更新知识图谱 D2-4 状态
- **验收**：项目代码 + 一段采样数据 + 周复盘笔记
